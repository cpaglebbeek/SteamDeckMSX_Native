## Scope v0.0.10

### 1. SoftwareDb class

`src/SoftwareDb.{h,cc}` (komt automatisch in `steamdeckmsx_core` via CMakeLists update):

```cpp
class SoftwareDb {
public:
    SoftwareDb() = default;
    int loadFromXmlFile(const QString &path);   // openMSX softwaredb.xml-formaat
    void addEntry(const QString &sha1Hex, const QString &machine, const QString &title);
    QString lookupMachine(const QString &sha1Hex) const;  // "" als niet gevonden
    QString lookupTitle(const QString &sha1Hex) const;
    int entryCount() const;
private:
    QHash<QString, QString> m_machines;  // sha1 → machine
    QHash<QString, QString> m_titles;
};
```

Test corpus (`test_softwaredb`): manual addEntry → lookup, XML-roundtrip met fixture-file.

### 2. RomTypeDetector::hashMatchSoftwaredb integratie

`Result.suggestedMachine` mag overschreven worden door softwaredb-hash-match
als generatie/mapper-heuristiek faalt of `MSX2plus` wordt voorgesteld:

```cpp
static Result detectWithSoftwaredb(const QByteArray &rom, const SoftwareDb &db);
```

### 3. Ascii8/16-mapper-detect

Heuristiek Z80 write-pattern:
- ASCII8: schrijf naar adres 0x6000, 0x6800, 0x7000, 0x7800
- ASCII16: schrijf naar adres 0x6000, 0x7000

Pattern-search in eerste 64KB ROM.

### 4. Auto-`setCurrentMachine` in MsxCore::loadRom

Voorwaarde: real-world accuratesse-rapport over ≥10 ROMs gemaakt; verifieer
≥90% match-rate tegen handmatige keuze vóór auto-switch vrijgeven.
