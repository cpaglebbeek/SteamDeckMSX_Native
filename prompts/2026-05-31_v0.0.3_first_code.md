## BUILD-OUTCOME — Mac smoke `cmake --preset native-debug` — ✅ SUCCES

| Stap | Resultaat |
|---|---|
| `brew install qt` (gestart background) + `brew install cmake ninja` | Qt 6.11.1, CMake 4.x, Ninja geïnstalleerd in /usr/local/opt/ |
| `cmake --preset native-debug` | Configure ✅ in ~8s. 2 cosmetische warnings (QTP0004 policy + ongebruikte STEAMDECKMSX_OPENMSX_DIR cache-var) |
| `cmake --build build/native-debug` | Build **FAILS** initieel: linker EISDIR — qt_add_qml_module maakte `src/steamdeckmsx/` dir conflict met exe-output `src/steamdeckmsx` |
| **Fix #1** (Geel-bug, RCA): target rename → `steamdeckmsx_app` met `OUTPUT_NAME=steamdeckmsx` | Niet voldoende — directory-conflict bleef bestaan |
| **Fix #2** (Geel-bug, RCA): `CMAKE_RUNTIME_OUTPUT_DIRECTORY ${BIN_DIR}/bin` | ✅ Build slaagt, exe in `build/native-debug/bin/steamdeckmsx` (Mach-O 64-bit) |
| App start headless (`QT_QPA_PLATFORM=offscreen`) | ✅ `SteamDeckMSX 0.0.3-Castlevania target= native` log-line bereikt; QML laadt; ApplicationWindow init |
| **QML-warning** "Could not attach Keys property to Main is not an Item" | **Fix #3** (Geel-bug): ApplicationWindow erft van Window niet Item → `Keys.onPressed` werkt niet → vervangen door `Shortcut` element met sequences ["Escape","B"] |
| Tweede smoke-run na fix #3 | ✅ Schoon, geen QML-warnings |
| Font-warning "Noto Sans Mono niet beschikbaar" | Verwacht op Mac (geen Noto-installatie); Steam Deck Freedesktop runtime heeft Noto bundeled — niet relevant |

**Conclusie:** UI-laag compileert + start schoon op Mac met Qt 6.11.1. 3 Geel-bugs gevangen + opgelost vóór commit (target-name conflict, runtime-output-dir conflict, Keys-op-Window-quirk). C++23 + Qt6 modern QML module-systeem werkt zoals voorzien.

**3 bugs zijn gedocumenteerd in BUGLIST.md** sectie "Opgelost". Patroon "qt_add_qml_module dir-conflict" is potentieel cross-repo relevant (Stream_Client zou ook QML kunnen gebruiken later) → kandidaat voor `Meta_Master/BUGS_GLOBAL.md` "FEATURE/QML".
