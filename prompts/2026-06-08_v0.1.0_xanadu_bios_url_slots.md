## 16 Design Decisions — kort

| # | Onderwerp | Keuze | Omkeer-tijd |
|---|---|---|---|
| DD-001 | HTTP/HTTPS | HTTPS-only | <5 min |
| DD-002 | Redirects | NoLessSafe (HTTPS→HTTPS auto) | <5 min |
| DD-003 | Max-size | BIOS 1 MiB / ROM 8 MiB | <2 min |
| DD-004 | Timeout | 30s | <1 min |
| DD-005 | Storage-locatie | `AppDataLocation/{bios,roms}` | <10 min |
| DD-006 | Persistentie | QSettings | ~30 min |
| DD-007 | BIOS-openMSX koppeling | Alleen administratie v0.1.0 | ~1-2 sessies |
| DD-008 | URL-dialog | Eén gedeelde met target-prop | ~15 min |
| DD-009 | Slot keuze-flow | Default A + shortcut S → SlotPicker | ~30 min |
| DD-010 | Shortcuts | I=BIOS, U=URL-ROM, S=Slot | <5 min |
| DD-011 | Atomic write | .part + rename | <10 min |
| DD-012 | Pad-veiligheid | `/` `\` → `_` sanitize | <10 min |
| DD-013 | SHA-1 berekening | Altijd | <5 min |
| DD-014 | Slot B Running-only | Hard weigeren niet-Running | ~30 min |
| DD-015 | addRom legacy | Alias addFromLocal(copy=false) | <5 min |
| DD-016 | Codenaam | Xanadu | — |

Volledige tekst in `docs/DESIGN_DECISIONS_v0.1.0.md`.
