## RCA — BUG-007 herhaal-preventie

Functioneel: tests konden nieuwe core-functies niet linken vanwege ontbrekende cc-files in target-list.
Technisch: directe `.cc`-paden in `add_executable(test_xxx ../src/Yyy.cc)` zijn fragiel — eke nieuwe file vereist edit op N plaatsen.
Architectuur: ontbrekend lib-target maakt het probleem structureel onmogelijk te ontwijken.

Fix: static-lib + `target_link_libraries(test_xxx PRIVATE steamdeckmsx_core)`. Nieuwe file in core → 1 file edit (`src/CMakeLists.txt`).
