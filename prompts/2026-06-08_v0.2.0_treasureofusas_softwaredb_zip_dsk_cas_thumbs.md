|---|---|---|

## 14 Design Decisions — kort

| # | Onderwerp | Keuze | Omkeer-tijd |
|---|---|---|---|
| DD-101 | SoftwareDb XML-parse | QXmlStreamReader (stream) | ~45 min |
| DD-102 | XML mapping (N hash/software) | Alle SHA's dezelfde meta | ~15 min |
| DD-103 | Hash-algo filter | sha1 only | ~30 min |
| DD-104 | Bulk vs per-entry signal | Bulk-emit op load, per-entry op addEntry | <5 min |
| DD-105 | Bootstrap-data | Hardcoded 5 sample-entries | <5 min |
| DD-106 | ZIP-lib | Qt-private QZipReader | ~2 uur (switch naar QuaZip) |
| DD-107 | Anti-zip-bomb | Per-file 1 MiB + 64 files/zip | <2 min |
| DD-108 | ZIP accept-extensies | .rom/.sys/.bin only | <2 min |
| DD-109 | DSK/CAS niet-Running | Auto-boot C-BIOS, dan loadDsk | ~15 min |
| DD-110 | DSK slot-routing | Default drive=0 (slot A) v0.2.0 | ~1 uur |
| DD-111 | Mapper-priority | SCC > ASCII16 > ASCII8 > Konami | <2 min |
| DD-112 | Thumbnails | `screenshot` Tcl-cmd (PNG-write) | ~2 uur |
| DD-113 | Thumbnail async-race | Accept v0.2.0; commandFinished v0.2.1 | ~1 uur |
| DD-114 | Codenaam | Treasure of Usas | — |

Volledige tekst in `docs/DESIGN_DECISIONS_v0.2.0.md`.
