## BUILD-OUTCOME — Mac smoke-test openMSX RELEASE_21_0 — ✅ SUCCES

| Aspect | Resultaat |
|---|---|
| brew deps geïnstalleerd | `sdl2_ttf`, `glew`, `tcl-tk` 9.0.3, `libogg`, `libvorbis`, `theora` (sdl2 + freetype + libpng al aanwezig) |
| Build-systeem | openMSX homemade Make (geen ./configure stap nodig — auto-detect via `build/*.mk` + Python helpers) |
| `make -j 8` resultaat | **EXIT=0** — schone build |
| Output binary | `derived/x86_64-darwin-opt/bin/openmsx` (Mach-O 64-bit x86_64) + bundle `derived/x86_64-darwin-opt/bindist/openMSX.app/` |
| Smoke-runnable | Niet getest (P-SDM-08, alleen "compileert?") |
| Linker-warnings | Cosmetisch — `building for macOS-10.15, but linking with dylib […] built for newer version 14.0` op SDL2/freetype/glew/theora/etc. Homebrew-libs targeten nieuwe SDK dan openMSX-default; werkt wel op Sonoma host. Niet relevant voor Steam Deck-build |
| Build-tijd | ~2 minuten op MacBook (8 cores) |

**Conclusie:** openMSX RELEASE_21_0 compileert + linkt + bundelt schoon op Mac met standaard Homebrew-deps. Bevestigt dat onze submodule-pin werkbaar is. Steam Deck Flatpak-build (v0.0.3) zal vergelijkbaar zijn met Linux-deps.

**Belang:** Mac ≠ support-target (P-SDM-08). Succesvolle smoke verschaft vertrouwen, géén support-belofte.
