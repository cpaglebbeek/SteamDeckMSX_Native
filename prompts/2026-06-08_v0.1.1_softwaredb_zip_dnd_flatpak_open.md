## Scope v0.1.1

### 1. ZIP-archief extract voor BIOS-sets

Veel BIOS-collecties zijn ZIPs (bv. openMSX-machines.zip). UI: BiosManagerScreen "+ ZIP" knop.
Implementatie: `QuaZip` (3rd-party) of Qt6 `QArchive` (experimental). Beslis bij sessiestart.

### 2. Drag-and-drop ROM/BIOS

CartridgeBrowser + BiosManagerScreen → `DropArea` met `keys: ["text/uri-list"]`. Bij drop:
```qml
onDropped: (drop) => {
    for (const url of drop.urls) {
        if (url.toString().endsWith(".rom")) cartridges.addFromLocal(url.toString())
        else if (url.toString().endsWith(".sys")) bios.addFromLocal(url.toString())
    }
}
```

### 3. .dsk / .cas ondersteuning in CartridgeBrowser

`MsxCore` uitbreiden:
- `loadDsk(path, drive)` → Tcl `diska <pad>` (of `diskb`)
- `loadCas(path)` → Tcl `casa <pad>`
- Detect extensie in CartridgeModel; juiste model-veld bv. `media-type`

### 4. Unit-tests v0.1.0 backfill

- `test_biosmanager` — fixture-files in `tests/data/dummy.rom` etc., addFromLocal + persist roundtrip + remove + clear
- `test_filedownloader` — mock-NAM patroon (subclass QNetworkAccessManager + override get)
- `test_msxcore_slots` — loadRomSlotA → start; loadRomSlotB niet-running → -1

### 5. Accessibility

- `Accessible.name` + `Accessible.role` op TextField en Button van UrlImportDialog + SlotPickerDialog + BiosManagerScreen
- Test met `Qt::QtAccessibleObject` inspector

### 6. Visuele wireframe-mockups Meta repo

Excalidraw-mockups voor `Meta_SteamDeckMSX/docs/screens/`:
- `04_biosmanager.excalidraw` — visueel BiosManagerScreen
- `05_urlimport.excalidraw` — UrlImportDialog
- `06_slotpicker.excalidraw` — SlotPickerDialog

### 7. Aparte Steam Input browser-preset

`presets/msx-browser.vdf` met I/U/S → KB-events. Onderscheiden van `Stream_Client/presets/msx-gamepad.vdf` (game-context).

### 8. ROM-extension auto-detect i.p.v. `.rom`-forceren

Huidige `resolveDestPath` forceert `.rom`. v0.1.1: gebruik `QMimeDatabase::mimeTypeForData` op de gedownloade bytes om correcte extensie te kiezen (`.rom`/`.dsk`/`.cas`/`.zip`).
