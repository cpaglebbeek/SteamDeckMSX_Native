## Wat moet v0.0.9 doen

### 1. Stap 21 — Flatpak-build op Steam Deck (6e poging)

Zie eerder geblokt resume-item — vereist Deck SSH-info.
```bash
flatpak-builder --force-clean build-flatpak nl.icthorse.SteamDeckMSX.yaml
```

### 2. Thumbnails save-state

openMSX framebuffer-XML-stream parse → base64 → `QImage`. Opslag:
- Linux/Flatpak: `~/.var/app/nl.icthorse.SteamDeckMSX/data/states/thumbs/slot_N.png`
- Mac dev: `~/.openMSX/savestates/thumbs/slot_N.png`

Hookup in `SaveStateModel`: nieuwe role `ThumbnailRole` → `SaveStateCard.qml` toont `Image { source: "file://" + thumbnailPath }`.

### 3. RomTypeDetector v2 — softwaredb-hash-match + Ascii-mapper

Uitbreiding (geen API-break):
- `static QString hashMatchSoftwaredb(QByteArray rom, QString softwaredbPath)`
  — SHA-1 ROM-bytes, zoek in `softwaredb.xml`, return matched machine
- Heuristiek: hash-match overschrijft size-based generation als gevonden
- `Mapper::Ascii8/16` detect via register-write-pattern (`F0 80 32 [60-77] [60-77]` ASCII8; vergelijkbaar voor 16)

### 4. Auto-`setCurrentMachine` na log-validatie

Voorwaarde: heuristiek-accuratesse-rapport over ≥10 ROMs (manueel testen + log-scrape). Pas vrijgeven als ≥90% accuraat. Bij twijfel: toast "Suggested machine: X (manual override available)".

### 5. Tab-strip in CartridgeBrowser

Main.qml-restructuur per `Meta_SteamDeckMSX/docs/screens/01_library.md`:
- TabBar bovenin met 3 tabs (Library / Streams / Settings)
- L1/R1 wisselt tab (huidige PageJump verschuift naar L2/R2 of dpad-modifier)
- iconBumperL1/R1 zichtbaar in tab-label
- Stream-tab is placeholder voor Stream_Client-integratie

### 6. Aparte Steam Input browser-preset

`presets/msx-browser.vdf` (in Native repo, niet Stream_Client):
- L1/R1 = tab-wisseling (KB-events Q/W of soortgelijk)
- L2/R2 = page-jump
- A = activate, B = back, Y = delete, X = SaveStateOverlay

Game-preset (`Stream_Client/presets/msx-gamepad.vdf`) blijft gescheiden — Steam Input wisselt automatisch op `flatpak run` exit-code.

### 7. ROM-header-parse publisher/year

`CartridgeModel` velden uitbreiden: publisher, year, regio. Heuristiek uit ROM-header (offset 0x10..0x20 conventie):
- Sommige Konami-ROMs hebben copyright-string
- Fallback: filename-pattern-match (bv. `bubblebobble.rom` → publisher onbekend, year onbekend)

### 8. Build + CI

- Mac smoke-test + ctest groen vóór commit
- Eventueel GitHub Actions workflow voor cross-platform CI (verschuift naar v0.1.0)
