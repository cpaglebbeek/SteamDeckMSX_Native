## Keuzes

| Keuze | Reden |
|---|---|
| **Pure static-functie-klasse** (geen Qt-state, geen QObject) | Trivial testbaar zonder Qt-event-loop; deterministische input → output |
| **Heuristiek size + SCC-pattern, geen softwaredb-hash nog** | Eerst real-world-accuratesse valideren via logs vóór auto-switch. Softwaredb-parse is significant werk en wacht op v0.0.9 |
| **SCC-detect = Z80 instructie-sequentie `3E 9F 32 B0 80`** | Konami SCC enable-write. 95%+ accuraat voor commerciële titels (Nemesis 2/3, SD-Snatcher, Salamander, F1 Spirit). Geen ROM-uitvoering nodig |
| **`MsxCore::loadRom` log-only (geen auto-`setCurrentMachine`)** | Veiligheid eerst — accuratesse valideren tegen werkelijke ROMs vóór gedrag te wijzigen. User zou een verkeerde auto-switch storender vinden dan handmatige keuze |
| **Max 512KB ROM-read** | I/O-cap; SCC-pattern zit in regel in eerste 64KB maar 512KB dekt ook MSX2 mega-ROMs zonder veel kosten |
| **L1/R1 = PageUp/PageDown (5 items)** ipv tab-strip | Tab-strip vereist Main.qml-restructuur — verschuift v0.0.9. PageJump is directe winst voor lange ROM-lijsten met minimale impact |
| **Steam Input mapping L1/R1 → PageUp/PageDown** | KB-events werken vandaag al; aparte browser-preset (≠ game-preset uit Stream_Client) komt v0.0.9 |
| **Codenaam Snatcher** | Konami MSX2 1988, Hideo Kojima's regie-debut, cyberpunk-adventure. "Detective-werk" past bij heuristisch onderzoek wat een ROM is |
| **Geen build/test-run deze sessie** | Codewise klaar. Mac smoke-test (`cmake --preset native-debug && cmake --build && ctest`) en/of CI verschuift naar v0.0.9-start. Risico laag: pure static-functie + bekend test-patroon |
