## Resultaat (alle gates groen, EXITSTATUS=0)

- **BUG-025 ✅ (cache):** flatpak-builder geeft `type: dir` letterlijk `builder_cache_checksum_random` ("always rebuild", broncode 1.4.2 r274-275). openmsx-module nu `type: git` uit fork `cpaglebbeek/openMSX-steamdeckmsx@dbf9612`; drift-guard in build-all stap 1 (negatief getest). Build 2: **`Cache hit for openmsx`** — ~8 min/ronde weg.
- **BUG-030 ✅ (ROOD, gevonden door de nieuwe gate):** het stdin-commandokanaal heeft nooit gewerkt — openMSX negeert `<command id=…>` stilzwijgend (gemeten 19.1 + eigen 21-fork: zonder id → `<reply result="ok">` + .oms-bestand), handshake `<openmsx-control>` ontbrak, replies dragen geen id. savestate/loadstate/pause/slot B/quit waren altijd no-ops; pauzemenu pauzeerde nooit echt. Fix: handshake + id-loos + XML-escaping + FIFO-correlatie. Unit-test T7 valideerde het verzonnen protocol via zijn eigen mock → aangepast.
- **BUG-029 ✅:** Save-states-knop in pauzemenu (X-toets was tijdens spel onbereikbaar: galerij verborgen); SaveStateModel toetst het echte reply-resultaat (toast pas na bevestiging, mislukte save geeft slot vrij); overlay-focusfix (BUG-027-familie: `onOpened: grid.forceActiveFocus()`).
- **Gate uitgebreid:** volledige roundtrip save → state-bestand op schijf → app-herstart → load bevestigd + beeld; app-data-wipe per run (run 2 testte per ongeluk een load door bezet-slot uit run 1); `[SaveState] … ok`-regels als hard bewijs. "Terugladen na herstart" is daarmee voor het eerst gemeten.
- **BUG-023 geïmplementeerd (hardware-test open):** `presets/controller_neptune.vdf` (D-pad/stick=pijltjes, A=Return, B=Esc, X=saves, Y=stop, Select=F12, L1=R, R1=I, rechter stick=muis); gepubliceerd naast de bundle (md5-gelijk); deck-deploy stap 6/7 zet hem in Steam Controller Configs per account (backup + fallback-instructie); footer-hint in galerij (visueel bevestigd op gate-screenshot).
- **BUG-031 (nieuw, geel, OPEN):** eigen BIOS-dumps (bv. `nms8245_disk_1.06`) verschijnen als speelbare tegel (BUG-019-filtergat); tegelkeuze gate niet deterministisch bij koude cache; cross-ROM-load zonder waarschuwing.
